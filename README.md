# Atom installers

Public **Windows installers only**. Application source lives in the private [diny-hou/atom](https://github.com/diny-hou/atom) repository.

## Download

Use **[Releases](https://github.com/diny-hou/atom-releases/releases/latest)** — not this git tree.

Typical files on each release:

- `Atom_<version>_x64-setup.exe` — NSIS installer
- `update.json` — Tauri v2 updater manifest (fetched by installed apps)

Installed copies check:

`https://github.com/diny-hou/atom-releases/releases/latest/download/update.json`
